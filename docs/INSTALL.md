# 安装与常见问题

## 自定义仓库安装

1. 确认卫月/Dalamud为兼容API15的Windows x64环境。
2. 若曾用开发插件方式加载同名ETDisplay，先停用旧实例，不要同时加载两份。
3. 在卫月设置中找到自定义/第三方插件仓库区域（入口名称随宿主版本不同）。
4. 添加并启用：
   `https://raw.githubusercontent.com/Catacatata/ETDisplay/main/repo.json`
5. 保存设置并刷新插件安装器，搜索ETDisplay，安装并启用。
6. 输入 `/etd`，按需要调整开关、音量、外观和浮层位置。

项目主页：<https://github.com/Catacatata/ETDisplay>

## 下载包的区别

- Release中的 `ETDisplay-1.0.0.2-rc2.zip` 是完整运行时包，包含主插件、Core、System.Speech运行时、清单和许可声明。
- 对应的 `ETDisplay-1.0.0.2-rc2-source.zip` 或GitHub自动生成的Source code是源码，不是插件安装包。
- 不要只复制ETDisplay.dll，遗漏依赖会导致加载失败。普通用户优先使用插件安装器，而非手动开发加载。

## 常见问题

### 仓库或下载打不开

需要本机可访问GitHub、raw.githubusercontent.com和Release资产下载服务。先检查链接和网络；不要把账号密码或访问令牌写入订阅地址，不建议使用来历不明的镜像插件包。

### 插件显示不兼容

确认宿主的Dalamud API版本为15。国服和国际服的更新节奏不同，不要强制绕过API检查；等待兼容版本。

### 没有中文语音或语音不可用

插件使用本机Windows语音，不提供统一语音包；未安装合适声音时可能使用英文回退，或显示不可用。文字、倒计时和SS显示不依赖语音可用性。

设置的高级页中有折叠排错工具；重试是显式操作，不会自动安装任何语音组件。打开设置本身不初始化语音，首次播报/试听前显示待命是正常情况。

### SS测试与实际系统事件不一致

按钮只验证内部提示路径，不证明真实消息匹配。真实SS仅接受当前实现的系统文本候选，不接受玩家或Echo复制的内容。请反馈语言、消息类型及脱敏后的必要文本，不要提交完整聊天或人名。

### 如何升级、退回旧版

正常通过插件安装器更新。遇到新版本问题先禁用插件，再反馈Build和复现步骤。必要时可按宿主支持的开发加载方式使用Release中的旧完整包，不要用零散DLL混装。修改配置前保留自己的备份；配置中没有云同步服务。

## 首次安装自检

- `/etd`可以打开常规页，开关和保存正常。
- `/echo ET 12:34`能更新显示；显示测试不发送玩家聊天。
- 外观预览静音、不改变实际目标。
- 倒计时和SS测试遵守开关、校准与冷却；清空可停止全部提醒。
- 重新加载后偏好保持，无重复回调。
